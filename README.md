# Finance Management System

A full-stack DBMS mini project using Python, SQLite, HTML, CSS, and JavaScript.

## Features

- Manage accounts and opening balances
- Create income and expense categories
- Add income and expense transactions
- Track monthly budgets
- View dashboard summary, recent transactions, and expense breakdown

## Tables Used

- `users`
- `accounts`
- `categories`
- `transactions`
- `budgets`



- The SQLite database is auto-created on first run.
- Demo data is seeded automatically for project presentation.
